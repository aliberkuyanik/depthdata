The opportunity / 04

Nobody needs a fifth dashboard. They need one definition.

Every AI vendor measures something different, and every one of them is measuring their own product's success, not yours. The gap is not more charts. It is a single definition of active, spend and value that holds across all of them, and that a finance team will sign off on.

The timing is not a hunch. It is in the matrix: vendors have started shipping read-only admin APIs, and a normalizing layer is only possible once they do. Where they still expose nothing, we say so.

Why now
Admin APIs exist. Six of eight tracked vendors expose seats, usage and spend today.
Budgets moved from experiment to line item, so someone now has to defend them.
Two of eight expose nothing but seats. That gap is published, not hidden.
The solution / 05

One schema. One baseline. Every number labelled.

It attaches to each vendor console with read-only scopes, translates their units into a single set of terms, and grades progress against what this workspace was doing in its first month. Nobody else's average is involved, so nobody can dismiss the result as someone else's company.

Measured
A vendor's own API said so. Seat counts, timestamps, invoices.
Derived
Arithmetic on the above. The formula is published, so you can redo it.
Modelled
An estimate. The method is written down and the range travels with it. Never dressed up as a count.

Other tools show you a number. This one shows you how much to trust it.

That is the whole product in one sentence. A dashboard that cannot tell you which of its figures were counted and which were estimated is asking you to take all of them on faith, and no CFO signs that.

Product walkthrough / 06

From four consoles to one defensible number.

Five steps. Each one answers a question the last one raised, and each one is published, so a sceptical analyst can follow the arithmetic end to end.

01 / ATTACH
Scopes, not software
A read-only grant per vendor. Nothing lands on anybody's laptop, so nothing needs approving.
02 / TRANSLATE
Six dialects, one language
Each vendor counts in its own units. They get rewritten into terms that can be added together.
03 / ANCHOR
Graded against you
Progress is scored against what this workspace did in month one, team by team.
04 / BOUND
A range, never a point
Anything estimated arrives with the width of its uncertainty attached.
05 / GRADE
Arithmetic you can audit
The health figure is a formula, and the formula travels inside every export.

Seats, sessions, invoices. Nothing anybody typed.

What a person wrote into a chat box is not an input to any figure on this page, and cannot be. Where a vendor's feed carries that text anyway, it is dropped before it is written down. There is no setting to turn that off, which is the point.
